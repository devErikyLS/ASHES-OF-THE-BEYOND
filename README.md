# Ashes of the Beyond

A 2D Dark Fantasy Action-Platformer developed with Unity.

## About the Project

**Ashes of the Beyond** is a 2D action-platformer set in a dark fantasy world filled with ruins, hostile creatures, and forgotten secrets.

The player must explore a decaying kingdom, face dangerous enemies, overcome challenges, and confront powerful bosses.

## Game Features

- 2D side-scrolling gameplay.
- Melee combat system.
- Challenging enemies and boss encounters.
- Platforming and exploration.
- Dark fantasy atmosphere.
- Pixel art visual style.

## Technologies

- **Game Engine:** Unity
- **Programming Language:** C#
- **Version Control:** Git and GitHub
